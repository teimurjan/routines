# Token contract

`design/tokens.json` is the one source of the style. `scripts/build-tokens.ts` writes two files from it. Do not edit them by hand.

## Source format

```json
{
  "color": {
    "canvas": { "light": "#FFFFFF", "dark": "#141415" },
    "text": { "light": "#000000D9", "dark": "#FFFFFFD9" }
  },
  "opacity": { "tint": 0.1, "pressed": 0.75 },
  "font": {
    "display": { "size": 26, "weight": "bold" },
    "body": { "size": 13, "weight": "regular" }
  },
  "space": { "1": 1, "2": 2, "28": 28 },
  "size": { "page-gutter": 28, "tab-min-width": 76 },
  "padding": { "button": { "x": 9, "y": 4.5 } },
  "radius": { "card": 14, "control": 7 },
  "shadow": { "card": { "opacity": 0.04, "radius": 2, "y": 1 } }
}
```

| Group | Value | Rule |
| --- | --- | --- |
| `color` | `{ light, dark }` | Each value is a hex color with 6 or 8 digits. The alpha comes last. |
| `opacity` | number | From 0 to 1. |
| `font` | `{ size, weight }` | The size is in points. The weight is `regular`, `medium`, `semibold` or `bold`. |
| `space`, `size`, `radius` | number | Points. CSS uses the same number in `px`. |
| `padding` | `{ x, y }` | Points. |
| `shadow` | `{ opacity, radius, y }` | A black shadow. The opacity is from 0 to 1. The radius is the blur radius. |

A `space` name is a number. Every other name is kebab case. A group that the file leaves out has no tokens.

The build fails in these cases:

- The file is not valid JSON, or it does not hold an object.
- It has a group that is not in the table.
- A name breaks the name rule of its group.
- A value breaks the rule of its group, for example a bad hex value or a weight that is not in the list.

## Outputs

### `app/Sources/Routines/Views/Tokens.swift`

```swift
// Generated by scripts/build-tokens.ts from design/tokens.json. Do not edit.
import SwiftUI

enum Tokens {
    struct Inset { let x: CGFloat; let y: CGFloat }
    struct ShadowStyle { let opacity: Double; let radius: CGFloat; let y: CGFloat }

    enum Color {
        static let canvas = SwiftUI.Color(light: 0xFFFFFFFF, dark: 0x141415FF)
    }
    enum Opacity {
        static let tint: Double = 0.1
    }
    enum Font {
        static let display = SwiftUI.Font.system(size: 26, weight: .bold)
    }
    enum Space {
        static let s28: CGFloat = 28
    }
    enum Padding {
        static let button = Inset(x: 9, y: 4.5)
    }
    enum Shadow {
        static let card = ShadowStyle(opacity: 0.04, radius: 2, y: 1)
    }
}
```

Each group becomes one enum: `Color`, `Opacity`, `Font`, `Space`, `Size`, `Padding`, `Radius` and `Shadow`. A kebab name becomes lower camel case, for example `card-border` becomes `cardBorder`. A `space` name gets the prefix `s`. A color gets 8 hex digits, and a 6-digit value gets the alpha `FF`.

### `packages/ui/src/tokens.css`

```css
/* Generated by scripts/build-tokens.ts from design/tokens.json. Do not edit. */
:root {
  --canvas: #FFFFFF;
  --opacity-tint: 0.1;
  --font-display-size: 26px;
  --font-display-weight: 700;
  --space-28: 28px;
  --size-page-gutter: 28px;
  --padding-button: 4.5px 9px;
  --radius-card: 14px;
  --shadow-card: 0 1px 2px rgb(0 0 0 / 0.04);
}
@media (prefers-color-scheme: dark) {
  :root {
    --canvas: #141415;
  }
}
```

| Group | CSS variable | Value |
| --- | --- | --- |
| `color` | `--<name>` | The light value. The dark value is under `prefers-color-scheme: dark`. |
| `opacity` | `--opacity-<name>` | The number. |
| `font` | `--font-<name>-size` and `--font-<name>-weight` | The size in `px`, and the weight as 400, 500, 600 or 700. |
| `space` | `--space-<name>` | The number in `px`. |
| `size` | `--size-<name>` | The number in `px`. |
| `padding` | `--padding-<name>` | `<y>px <x>px`. |
| `radius` | `--radius-<name>` | The number in `px`. |
| `shadow` | `--shadow-<name>` | `0 <y>px <radius>px rgb(0 0 0 / <opacity>)`. |

Hex values are upper case in both outputs. SwiftUI and CSS draw a shadow blur in different ways. If the two look different, change the shadow token, not one output.

`--accent` is not a token. `@routines/ui` sets it from the accent color of the Mac in the snapshot.

## Commands

| Command | Result |
| --- | --- |
| `bun run tokens` | Writes each output that differs from the source. |
| `bun run tokens --check` | If an output differs from the source, the command fails. `bun run check` runs it. |

`scripts/build-tokens.test.ts` covers the parser and both outputs.
